# Input Buffer Dynamic (Geode mod, Windows)

Press **Tab** in game to open the settings.

This is the release of the input buffer geometry dash exploit named (Dynamic) this one is only compatable with the geode version V.5.11.2
if your geode version is Newer wait for the next Release.

## Requirements
- Windows 11 (other operating systems will get their own releases later)
- Geometry Dash 2.208 (on a newer version like 2.209 you need to wait for the next release of the mod)
- Geode 5.11.2

## How to install
1. Download **V5.11.2.input-buffer-dynamic.geode** from the Assets section below.
2. Open Steam, Open **Geometry Dash**.
3. Click on the **geode** Icon down below, then go to **settings for geode (The Gear Icon)** .
4. Click install from file.
5. Now in the Explorer which Geode should have put you in click **V5.11.2.input-buffer-dynamic.geode** and proceed to install.
6. Restart Geometry Dash .
7. Click the Geode button on the main menu and open the **Installed** list. **Input Buffer Dynamic** should be there with a checkmark.

## How to use
Press **Tab** in the game to open the settings. Change one slider at a time and test it on a part of a level you keep failing.

Suggested values (untested guesses, adjust by feel):
- Cube / Ball / Robot / Spider buffer: 8 to 12 ms
- Ship / UFO / Swing min hold: around 4 ms
- Wave min hold and min gap: 1 to 4 ms

Do not set the values too high, or the auto correction will make the game harder, especially in wave.

## Problems
- Mod not showing up: check that your Geode and game versions match and that the file is directly inside the mods folder.
- Click Between Frames conflicts with this mod, so untick it while you use it.
- If Tab opens another menu too (for example Eclipse), change the menu key in that mod.
